# M1 原始雷达采集清单（给周震宇）

> 一句话目标：用 IWR6843AOP 采**原始点云 `.bin`**（8 类动作含跌倒），喂进后端雷达管线。
> 详版规程见 `docs/data-collection-protocol.md`，本清单是可直接照着做的精简版。

## 0. 为什么这次要采"原始帧"（重要）
同学之前给的两段（坐/走）是 **`.jsonl` 回放体征**（已算好的 breath/heart，还写着 `source=replay_*.json`），
**不是原始雷达帧**，只能做前端演示，跑不了真实全流程。真实链路要吃的是：

```
IWR6843AOP DATA UART → capture_oob.py 解析 OOB TLV → 每帧点云 (N,3) .bin
  → 后端 load_mmwave_frames / RadarPhaseProvider → 相位 → 生命体征 + 行为 CNN
```

**缺原始点云 = 生命体征和行为识别都跑不动。**

## 1. 硬件
- IWR6843AOP EVM + 5V/≥2.5A 电源 + micro-USB 数据线 ×1
- 上位机（Windows/Linux，Python 3.11+）
- 雷达支架：高 1.0–1.5 m，朝向人体胸腹（模拟实际安装）
- **跌倒类铺安全垫**

## 2. 固件与连接
1. 装 TI mmWave SDK（3.6.x），取 AOP demo 固件 `xwr68xx_aop_mmw_demo.bin`，用 **UniFlash** 烧录。
2. micro-USB 连 PC，设备管理器出现两个 CDC 口：
   - **CLI UART**（115200）：配参（默认 demo 可免配直接出点云）
   - **DATA UART**（921600）：点云输出口 —— 采集脚本连这个
3. 跑 `edge/capture_oob.py` 连 DATA 口。

## 3. 采集命令
```bash
cd 项目根
pip install pyserial numpy          # 采集机只需这俩
python edge/capture_oob.py \
    --port COM5 \                   # 改成你的 DATA UART 口
    --baud 921600 \
    --out data/radar/E01/S01/A01/mmwave \
    --seconds 30
```
跑完生成 `frame0000.bin ... frame00NN.bin`（每帧 `(N,3)` float64 点云）。

## 4. 八类动作对照（与 BehaviorAction 对齐）
> 每类 **≥10 次重复**，每次 **10–30 秒**；受试者 **≥3 人**；环境固定（同房间、同高度、同朝向）。

| A 类 | 动作 | 映射 | 安全属性 |
|---|---|---|---|
| A01 | 走动 walking | `walking` | 正常 |
| A02 | 站立 standing | `standing` | 正常 |
| A03 | 静坐 sitting | `sitting_still` | 正常 |
| A04 | 躺床休息 lying | `lying` | 正常（需与倒地区分） |
| A05 | 起身 standing_up | `standing_up` | 正常 |
| A06 | 弯腰/蹲下/拾物 crouching | `crouching` | ⚠️ 易误判跌倒，必须单类 |
| A07 | 倒地不起 lying_floor | `lying_floor` | 🔴 跌倒后状态 |
| A08 | **跌倒 falling** | `falling` | 🔴 P0 红警，自有采集重点 |

> `normal_activity` 仅作"未知/其他"低置信兜底，不单独采集。

## 5. 目录规范（标签即文件夹，无需单独标注文件）
```
data/radar/
  E01/                 # 环境 1
    S01/               # 受试者 1
      A01/mmwave/frame*.bin   # 走动
      A02/mmwave/frame*.bin   # 站立
      ...
      A08/mmwave/frame*.bin   # 跌倒
```

## 6. 离线自检（无需硬件，采完即可本地验证）
```bash
python -c "from backend.app.inference.mmwave_cnn.preprocess import load_mmwave_frames; \
f=load_mmwave_frames('data/radar/E01/S01/A01/mmwave'); \
print('帧数', len(f), '首帧形状', f[0].shape if f else None)"
```
应看到 `帧数 > 0`、形状 `(N, 3)`。若首帧解析不出点，对照你 SDK 的 `mmw_output.h` 校正 MAGIC/偏移。

## 7. 跌倒类安全规范（必须遵守）
- `falling` 用**慢动作排练**（坐倒/滑倒/跪倒/扶墙下滑）+ 地面垫 + 旁人保护，**严禁真实自由落体**。
- 受试者签简易知情同意（校内大创，记录年龄/体型区间即可，脱敏）。

- 这是物理/后勤任务，不是纯代码：需要实验室空间、受试者、时间、同意。
